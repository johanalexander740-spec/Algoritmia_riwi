# Algoritmia - Riwi

Colección de ejercicios y prácticas de lógica de programación y algoritmos desarrollados durante el módulo de **Algoritmia** en Riwi.

## Contenido

- **`Caracol/`**: Ejercicio de lógica en JavaScript.
- **`Semana-1/`**: Algoritmos secuenciales básicos en PSeInt  (cálculo de áreas, conversiones, promedios, presupuestos).
- **`Semana-2/`**: Estructuras de control condicionales en PSeInt (validación de datos, semáforos, parqueadero, año bisiesto).
- **`Semana-3/`**: Estructuras repetitivas y ciclos en PSeInt  (acumulación de ahorro, validación de PIN).

## Tecnologías

- **PSeInt** (Pseudocódigo)
- **JavaScript** (Node.js / ES6)
